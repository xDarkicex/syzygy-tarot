About

Syzygy is a modern revisioning of xDarkicex/tarot, originally a Java console reader. This version keeps the numerology-driven daily reading and the original three-card spread (Hear Me / Help Me / Hold Me), while adding a web GUI and reversed meanings for all 78 cards.

The original bug, fixed

The Java source declares a reversed field on every card but never populates it. Reversed draws print a blank. This revision authors a genuine shadow reading for every card and lets the GUI show it when the dealt card is reversed.

The seed

The shuffle is seeded from your name length, age, resonance choice, and the day of the year, then divided by your age. So the same person gets the same reading all day. The full calculation is shown on every reading under The numerology behind this reading.

Profiles

Profiles live in your browser's localStorage, mirrored into a signed cookie so the server can prefill the form. Nothing leaves the SQLite file on this device.
